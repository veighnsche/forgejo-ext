feat: private repositories can now grant other repositories' Actions jobs read access to them. A new per-repository "Actions access" setting (repository Settings, Units) lets a private repository be read by workflows in other repositories: `none` (default, unchanged), `same-owner` (repositories owned by the same user or organization), or `same-org` (repositories owned by the organization or by a member of it). It is also settable through the repository edit API (`actions_access_scope`), is read-only, leaves public repositories unaffected, and must be enabled instance-wide with `[actions] CROSS_REPO_ACCESS_ENABLED`.
