Move internal communication to UNIX socket. The `INTERNAL_TOKEN` can now be dropped from the configuration, the UNIX socket path and permissions can be configured using the `INTERNAL_LISTENER_PATH` and `INTERNAL_LISTENER_PERMISSIONS` options. This change removes the `./forgejo generate secret INTERNAL_TOKEN` command and updates the contrib Forgejo systemd unit file.<br>See the [documentation](https://forgejo.org/docs/latest/admin/config-cheat-sheet/#server-server) for more information.
